# 剧情听写 Scene Dictation

一个 desktop-first 的英语听写训练网站：看剧情画面 → 理解语境 → 输入英文台词 → 逐字反馈 → 答对后听原句 → 跟读录音 → 查看每日学习统计。

纯原生 HTML / CSS / JavaScript，无第三方依赖、无构建步骤，可直接部署到 GitHub Pages。

## 本地运行

任何静态服务器均可，例如：

```bash
python3 -m http.server 8788 -d .
```

然后访问 `http://localhost:8788`。（直接双击 index.html 也能打开，但建议走本地服务器。）

## 部署到 GitHub Pages

1. 把本目录推到 GitHub 仓库。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`。
3. 等待约一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 内容与版权

- `content.js`：内置课程，**进入公开仓库**，只允许原创内容、标注过的模拟内容或公有领域素材。当前示例课程《枫叶街》的台词与插画均为原创。
- `content.local.js`：个人学习内容模板。你自己听写用的真实剧集台词（例如某部电视剧的字幕）写在这里，**填入真实台词后不要把改动提交到公开仓库**——剧集台词受版权保护，个人使用与公开发布是两回事。
- 本仓库不包含、也不得加入任何未授权的电视剧视频、字幕、原声或演员图片。

## 本地视频模式

选择 `mediaMode: 'local'` 的课程时，页面会出现「选择本地视频」按钮：

- 从你的电脑选取你合法拥有的视频/音频文件，通过浏览器的 blob URL 在页面内播放。
- 文件**不上传、不写入仓库、不进入 localStorage**，只存在于当前页面会话。
- 每句可配置 `startTime` / `endTime`（秒），答对后「播放原句」会精准重播该片段。

## 字幕导入（自动生成听写句）

本地课程的视频下方有「导入字幕（.srt）」按钮：

- 选一个本集的 `.srt` 字幕文件，自动解析成整集的听写句，每句自带起止时间，不用手写任何配置。
- 双语字幕按"是否含汉字"拆分：中文行作为题面提示，英文行作为听写答案；纯英文字幕也可用（题面显示"先听片段再输入"）。
- 自动清理 `<i>` 等标签、`{\an8}` 特效码、行首对话短横线；纯音乐符号/纯中文的条目跳过。
- 文件编码兼容 UTF-8 和 GBK（中文字幕常见编码）。
- 解析结果保存在**本机浏览器 localStorage**，刷新后字幕句子仍在（视频仍需重选）；重新导入即覆盖。
- 字幕文件与视频一样只在本地使用，`.gitignore` 已封死 `*.srt` 等后缀，不会进入仓库。
- 句子超过 20 句时，底部导航自动从圆点切换为「已完成 n / N + 跳转框」。

## 没有字幕文件？本地 AI 转写

视频没有配套 `.srt` 时，可以用 Whisper 在本机离线生成（英文字幕，不上传任何内容）：

```bash
# 一次性准备：安装工具 + 下载模型（约 466MB，放 models/ 目录）
brew install ffmpeg whisper-cpp
curl -L -o models/ggml-small.en.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.en.bin

# 每集一条命令，输出与视频同名的 .srt
tools/transcribe.sh 1/S01E01.mp4
```

实测 Apple 芯片上约 1 分钟处理 5 分钟音频；`models/`、`*.srt` 均已被 `.gitignore` 拦截，不会入库。

## 已知边界

- **刷新后需要重新选择本地视频文件。** 这是浏览器安全机制（页面无法记住并自动重新读取本地文件），不是 bug；页面会提示上次选择的文件名帮你找回。
- 学习统计和完成进度保存在浏览器 `localStorage`，最多保留最近 90 天。**换浏览器、清理浏览器数据或换设备后数据不会同步**，第一版没有账号和云端备份。
- 单词朗读和无音频时的原句朗读使用浏览器内置语音（SpeechSynthesis），不同系统的音色和可用性有差异。
- 跟读录音只保存在当前页面内存中，刷新即消失，不会上传。
- 有效学习时长的口径：页面可见且最近 90 秒内有键盘/鼠标操作时，每 15 秒累计一次；单纯挂着网页不计入。

| `app.js` | 全部页面逻辑（听写判定、声音、录音、统计） |
